# 忠泰美術館電子郵件簽名檔產生器
純靜態網站，無後端、分析追蹤、表單提交或本地資料儲存。GitHub Pages 本身可能保留一般網站存取紀錄；不含表單輸入內容。

部署：建立 GitHub repository（公開發布前確認品牌圖檔授權），上傳 index.html、logo.png、README.md 至 main 根目錄。Settings > Pages > Build and deployment > Deploy from a branch > main / (root) > Save。以 Pages 顯示的 HTTPS 網址開啟。不要上傳原始內部規範或含個資的範例。

本機可直接開啟 index.html 預覽；正式使用請透過 HTTPS，因富文字剪貼簿及郵件圖片需要適當環境。LOGO 使用忠泰美術館十週年圖檔。Outlook/Gmail 可能重寫連結、移除圖片或替換字型；正式上線前請實際寄送測試信，必要時在郵件編輯器重插 LOGO。手機選填，其餘欄位必填。複製後的內容仍可由郵件軟體編輯，並非不可修改的簽名政策。
